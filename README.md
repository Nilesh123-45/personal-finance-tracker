#  Personal Finance Tracker

A Full Stack finance manager built to track expenses, set strict monthly budgets, and visualize spending habits. 

**Note:** Coming from a **Java/Spring Boot** background, this project was my deep dive into the **Node.js** ecosystem. I developed as per the instructions by a reputed Company.

##  Key Features
* **Strict Budgeting:** Visual progress bars that turn RED and *block* transactions if you overspend.
* **Recurring Income:** Automatically generates monthly Salary/Weekly allowance entries (Backend Logic).
* **Analytics:** Live Doughnut chart comparing Income vs. Expenses.
* **Security:** JWT Authentication & Bcrypt password hashing.

##  Tech Stack
* **Frontend:** Vanilla JS, HTML5, Modern CSS (Glassmorphism).
* **Backend:** Node.js, Express.js.
* **Database:** MySQL.
